Огонёк на экран телефона

Новый виджет: логотип, центральный огонёк и твоя серия. Молочный фон, зелёные формы и четыре цветовых этапа: 1–30, 31–60, 61–90 и 91+. Вся графика уже внутри скрипта.

1. Вставь код

Установи Scriptable. На экране Untitled Script 1 удали весь старый текст: коснись кода, выбери всё и удали.

Если кнопка копирования не сработала

Нажми на поле ниже, выбери весь текст и скопируй. Не копируй заголовок или номера строк.

Вернись в Scriptable, вставь код вместо удалённого, назови скрипт Java Lab и нажми ▶ → Маленький виджет. Число будет взято из твоего прогресса.

2. Подключи чтение прогресса

Если виджет уже подключён, просто замени код и запусти: прежний ключ сохранится. Для замены ключа используй настройку при запуске.

Если ключ попал в чат или на скриншот, его нужно отозвать. Создай новый на срок около года: Only select repositories → java-backend-lab → Contents: Read-only. Metadata: Read-only GitHub добавит сам.

После запуска скрипт покажет окно: вставь новый ключ в поле GitHub token, в поле «Ветка» оставь main и нажми «Сохранить». Ключ сохранится в Keychain iPhone; в код его вписывать не надо.

3. Поставь виджет

На главном экране зажми пустое место → добавь маленький виджет Scriptable → в настройках виджета выбери скрипт Java Lab.

Нажатие на виджет откроет учебный кабинет. Один раз подключи GitHub в кабинете и включи «Запомнить на моём устройстве». Затем завершения отправляются автоматически, пока кабинет открыт. Виджет читает отправленную копию. Обновление зависит от iOS и может занять время.

Подпись Scriptable под виджетом поменять нельзя. Имя Java Lab видно внутри огонька. Для отдельной иконки открой кабинет → Поделиться → На экран «Домой» → Java Lab → включи «Открыть как веб-приложение». Если Яндекс открывает обычную вкладку, установи через Safari. Для обновления иконки сначала дождись «✓ В GitHub» или скачай копию прогресса, затем замени старый ярлык новым. Переход из виджета может открыть браузер: iOS сама выбирает приложение.
