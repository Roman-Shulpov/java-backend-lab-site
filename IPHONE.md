# Java Lab · iPhone-виджет

## Обновить существующий виджет

1. Открой [установку](https://roman-shulpov.github.io/java-backend-lab-site/iphone.html) и нажми «Скопировать готовый код».
2. В Scriptable открой Java Lab, выдели весь старый код и замени новым целиком. Нажми ▶ → «Маленький виджет».
3. Уже сохранённые ключ и ветка сохранятся. В настройках домашнего виджета оставь Script: Java Lab.

Готовый файл: [Java-Lab-Widget.js](Java-Lab-Widget.js). Он включает графику: отдельные файлы на iPhone переносить не нужно. Никогда не вставляй ключ в код.

## Как выглядит

В маленьком размере: логотип, центральное пламя, число и «день/дня/дней подряд». У 0 — нейтральное пламя. Цвета по новому ТЗ виджета:

| Серия | Огонёк |
|---|---|
| 1–30 | Оранжевый, жёлтая сердцевина |
| 31–60 | Красный, оранжевая сердцевина |
| 61–90 | Magenta / violet |
| 91+ | Сиренево-фиолетовый, дополнительные блики |

Счётчик не ограничивается 90. Все варианты пламени имеют одинаковую рамку и положение. Для четырёх и более цифр предусмотрено уменьшение шрифта. Для небольшого экрана используется компактная геометрия.

В меню при запуске внутри Scriptable доступны маленький и средний предпросмотры, замена ключа и проверка синхронизации. На домашнем экране размер выбирается при добавлении виджета; семейство medium определяется автоматически. Только средний размер показывает дополнительную информацию о неделе.

## Прогресс и связь

Источник прежний: закрытый java-backend-lab, progress/state.json, ветка main или выбранная в настройке. Для виджета нужен fine-grained key только к этому репозиторию, Contents: Read-only. Он хранится в Keychain. Если подключения нет, виджет показывает нейтральный 0, а настройка доступна при запуске скрипта.

Расписание и подсчёт серии используют общий движок сайта: ПН/СР/ПТ, время Барнаула. Отдых сохраняет серию; повторные отметки одной даты не увеличивают число. Открытие приложения или запуск виджета ничего не начисляет. Длительная серия и повторение пройденного работают по прежним правилам.

Для автоматической отправки отметок из кабинета один раз подключи сайт к GitHub отдельным ключом Contents: Read and write и по желанию включи «Запомнить на моём устройстве». После занятия дождись «✓ В GitHub» перед закрытием. Отправка работает при открытом кабинете и доступной сети.

Если GitHub недоступен, виджет сохраняет последнее проверенное значение на момент загрузки кеша. Он не делает вывод о пропущенном занятии по устаревшим данным. При отсутствии достоверного кеша — 0. Дату и источник можно посмотреть через «Проверить синхронизацию» в Scriptable. Ошибка записи кеша не скрывает успешно полученные онлайн-данные.

Картинки не скачиваются из интернета: PNG встроены в JavaScript, один раз сохраняются в локальный кеш. Если изображение недоступно, используется резервная отрисовка через DrawContext. Нажатие на виджет открывает главную кабинета. iOS определяет фактическое время обновления, запрос выставлен через 15 минут.

## Ярлык веб-приложения

Открой [кабинет](https://roman-shulpov.github.io/java-backend-lab-site/#home) → Поделиться → На экран «Домой» → Java Lab → «Открыть как веб-приложение». Если Яндекс открывает вкладку, используй Safari. Перед заменой старого ярлыка синхронизируй прогресс или скачай резервную копию. Системная подпись Scriptable под виджетом задаётся iOS.

## Проверка и сборка

- Векторные исходники и PNG: assets/. Сборка: node app/build_widget_art.cjs (нужен sharp).
- Нативная компоновка: widget-ui.js. Общий календарь: ../dist/rhythm.js.
- Самостоятельный файл собирается командой python app/build_widget.py.
- Проверка логики и API-дублёров: node app/tests/widget.test.cjs.
- Растровая проверка геометрии: node app/preview_widget.cjs. [Матрица десяти значений](previews/widget-states.png) — тестовый макет, не скриншот iOS. Настоящий предпросмотр выполняется на iPhone через presentSmall()/presentMedium().

API сверены с официальными страницами [ListWidget](https://docs.scriptable.app/listwidget/), [WidgetStack](https://docs.scriptable.app/widgetstack/), [WidgetText](https://docs.scriptable.app/widgettext/), [WidgetImage](https://docs.scriptable.app/widgetimage/), [DrawContext](https://docs.scriptable.app/drawcontext/), [Path](https://docs.scriptable.app/path/), [Image](https://docs.scriptable.app/image/), [Data](https://docs.scriptable.app/data/), [Font](https://docs.scriptable.app/font/), [Device](https://docs.scriptable.app/device/) и [FileManager](https://docs.scriptable.app/filemanager/).
