# Огонёк на iPhone

Это настоящий виджет через приложение **Scriptable**. Он читает отправленный в GitHub прогресс, показывает занятия недели и открывает следующий урок. Устанавливается один раз на телефоне; компьютер может быть выключен.

## Настроить

1. Установи [Scriptable](https://scriptable.app/) на iPhone.
2. На GitHub открой [создание fine-grained token](https://github.com/settings/personal-access-tokens/new) в настройках **аккаунта**. Назови `Java Lab iPhone`, выбери срок примерно год, **Only select repositories → java-backend-lab**, Repository permissions → **Contents: Read-only**. GitHub сам добавит Metadata: Read-only. Account permissions оставь пустыми. Скопируй токен для следующего шага; в чат его отправлять не нужно.
3. На iPhone открой [код виджета](https://github.com/Roman-Shulpov/java-backend-lab-site/blob/main/Java-Lab-Widget.js) и нажми значок копирования содержимого файла. В Scriptable создай скрипт `Java Lab`, вставь код целиком и запусти.
4. В окне самого Scriptable вставь токен и укажи ветку, куда кабинет отправляет progress/state.json: сначала `main`, позже может быть `learning/m01`. Токен сохраняется в Keychain телефона, не в коде.
5. Удерживай пустое место на главном экране → добавь маленький виджет Scriptable. В настройках виджета выбери скрипт **Java Lab**. В поле Parameter можно указать другую ветку без изменения кода.

После занятий нажимай в кабинете «Сохранить в GitHub». Без этой кнопки виджет видит предыдущую отправленную версию. При объединении учебной ветки в main верни Parameter к main.

## Что означает огонёк

Три разных дня с работой за неделю, понедельник–воскресенье, время Барнаула. Повторная отметка в один день не увеличивает число дней. Выходные не обрывают серию заранее: считается завершённая неделя. После неудачной недели прошлые уроки остаются выполненными; следующая работа снова зажигает огонёк.

iOS сама выбирает момент обновления; скрипт просит проверку примерно через час, но точное время не гарантируется. Без сети показывается помеченная сохранённая копия. Если доступа нет совсем, виджет показывает ошибку, а не выдуманный нулевой прогресс.

## Границы первой версии

Виджет **показывает** прогресс; галочки ставятся в [кабинете по ссылке](https://roman-shulpov.github.io/java-backend-lab-site/) или в локальном кабинете на компьютере. После отметок нажимай «Сохранить в GitHub». Нажатие на виджет открывает урок на GitHub в Safari, где нужно войти в свой аккаунт. Иконка сайта на главном экране и виджет — разные вещи.

Сам скрипт и расчёт серии проверены на компьютере; установка, внешний вид и обновление на твоём iPhone требуют запуска на устройстве. Если токен истёк: выполни в отдельном временном скрипте `Keychain.remove('java-backend-lab-read-token')`, затем снова запусти Java Lab и введи новый. Старый токен отзови на GitHub.
