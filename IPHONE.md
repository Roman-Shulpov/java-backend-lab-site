# Java Lab на iPhone

## Иконка приложения — один раз

1. Открой https://roman-shulpov.github.io/java-backend-lab-site/#home и обнови страницу.
2. Поделиться → На экран «Домой». Имя: **Java Lab**. Оставь **«Открыть как веб-приложение»** включённым → Добавить.
3. Если уже был старый ярлык с буквой J, удали только ярлык и добавь заново. Если Яндекс открывает вкладку, выполни установку через Safari. Установленный ярлык — самый надёжный вход в отдельное окно.

## Огонёк — один раз обновить скрипт

1. Открой [страницу установки](https://roman-shulpov.github.io/java-backend-lab-site/iphone.html) → **Скопировать готовый код**.
2. Scriptable → твой скрипт Java Lab → выдели весь старый код → вставь новый целиком → ▶. Не дописывай код к старому.
3. Уже подключённый ключ сохранится. При необходимости выбери «Заменить ключ». Новый ключ: Only select repositories → java-backend-lab → Contents: Read-only; ветка main. Вводи ключ только в окно настройки. Не добавляй его в код или переписку.
4. На домашнем экране зажми виджет → Изменить виджет → Script: Java Lab. При наличии настройки When Interacting выбери Run Script. Внутри будет Java Lab; системная подпись Scriptable под виджетом не переименовывается.

## Чтобы отметки приезжали сами

Открой установленный кабинет → **Подключить GitHub**. Для сайта нужен отдельный ключ только к java-backend-lab с **Contents: Read and write**, ветка main. Включи **«Запомнить на моём устройстве»**. Это добровольно сохраняет ключ в памяти браузера данного сайта; без галочки он живёт до закрытия вкладки. Сделай это на каждом своём устройстве, где занимаешься. Ключ виджета остаётся только для чтения.

После завершения занятия дождись **«✓ GitHub»** сверху перед закрытием. Без сети отметка сохранится здесь, отправка повторится при открытом кабинете и восстановлении связи. Закрытый сайт не обещает фоновой отправки. После первого открытия онлайн уроки сохраняются для работы без сети; очистка данных браузера удаляет эту копию. На новом устройстве открывай сайт онлайн.

Виджет запрашивает обновление примерно раз в 15 минут, но время выбирает iOS. Для немедленного просмотра запусти скрипт в Scriptable. Без сети виджет показывает подписанную копию последних данных. Нажатие ведёт на главную кабинета; iOS может открыть браузер вместо установленного веб-приложения.

## Понедельник · среда · пятница

- Учебный день: огонёк ждёт завершённого урока; после завершения горит.
- Вторник/четверг/выходные: отдых. Состояние последнего учебного дня сохраняется.
- Не закончил в понедельник: во вторник огонёк ещё не горит; можно доделать урок и зажечь его. В среду нужен новый результат.
- «Поработал, продолжу позже» заполняет календарь, но не зажигает огонёк.
- Несколько уроков в один день не закрывают будущие учебные дни. Снятие отметки превращает её в практику.
- Время считается по Барнаулу. Пауза не удаляет проекты и пройденные уроки.

График клеток показывает настоящую учебную работу за год, а не число Git-коммитов. Никаких искусственных отметок.
